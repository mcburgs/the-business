# Canonical schema integration point

The governing Phase 0 contract identifies `schemas/we.phase0.schema.json` as the canonical JSON Schema Draft 2020-12 definition set, with wrapper schemas and semantic validation.

Those machine-consumable files were not included in the source attachments available to this Phase A build. They are therefore intentionally **not reconstructed from prose** here.

When the actual Phase 0 schema package is supplied, place/integrate it under this boundary without changing identity, reference, command, hidden-information, save, or Chronicle semantics as a local convenience.
